  사용 방법
  
    
    
  1. 테스트 영역에서 글자를 고치거나, “HTML 소스 편집”에서 태그·속성을 바꿉니다. (예: <li> 추가, class="done" 부여, <p> → <h3>)
    2. 
    
  2. Patch: 테스트 영역 → 새 Virtual DOM → 이전 VDOM과 Diff → 변경된 부분만 실제 영역에 반영(노란 깜빡임) → State History에 저장.
    3. 
    
  3. 뒤로가기 / 앞으로가기: 저장된 VDOM으로 이동. 실제 영역은 두 State 사이의 Diff 패치로, 테스트 영역은 해당 VDOM으로 다시 그립니다.
    4. 
  

  
이 구현은 key 없이 “같은 위치끼리” 비교합니다. 보안을 위해 script/style/iframe 등과 on* 속성, javascript: 링크는 VDOM 변환에서 제외돼요.

  사용 방법
  
    
    
  1. 테스트 영역의 HTML 코드를 직접 고칩니다. (예: <li> 추가, class="done" 부여, <p> → <h3>, 글자 수정)
    2. 
    
  2. Patch: 테스트 영역의 HTML → 새 Virtual DOM → 이전 VDOM과 Diff → 변경된 부분만 실제 영역에 반영(노란 깜빡임) → State History에 저장.
    3. 
    
  3. 뒤로 / 앞으로: 저장된 VDOM으로 이동. 실제 영역은 두 State 사이의 Diff 패치로 바뀌고, 테스트 영역은 해당 VDOM의 HTML 코드로 바뀝니다.
    4. 
  

  
이 구현은 key 없이 “같은 위치끼리” 비교합니다. 보안을 위해 script/style/iframe 등과 on* 속성, javascript: 링크는 VDOM 변환에서 제외돼요.
